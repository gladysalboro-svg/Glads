05 — Developer Mindset

Development is a loop, not a straight line

Learn it→ Build it→ Break it→ Understand why→ Fix it→ Try again

Most of what I know now, I know because something did not work and I had to find out why. That is not a detour from the work — that is the work. Every broken build is a concept finally becoming clear.

Perseverance

The first version being wrong is expected. I keep going until it works.

Continuous learning

I don't want to be "done". I want to be getting better.

Honest documentation

If a feature is not finished, the README says so. I would rather be accurate than impressive.
